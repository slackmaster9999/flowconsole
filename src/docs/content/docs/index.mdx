FlowConsole is an open source project(alpha) with a goal to create an Architecture as Code Platform that helps developers and architects 
to have a single source of truth for systems that they are building and laverage their favorite programming languge, ide, git, etc.

We started small, we built a Typescript Fluent API and an engine that can generate architecture diagrams. 
So you can forget all the hustle with placing elements and how to connect it together to minimize the intersections of edges. 

Check out our [roadmap](https://github.com/slackmaster9999/flowconsole?tab=readme-ov-file#roadmap) to see what we are planning to do next.

Let's get started!
